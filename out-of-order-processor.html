Computer architecture / Digital design

Inside an out-of-order processor.

A completed five-person EECS 472 team project: a two-wide R10K-style out-of-order RISC-V processor built on the course VeriSimpleV infrastructure.

MY ROLE

Contributions across nearly all parts of design, integration, debugging, and verification

The architecture

The processor uses physical-register renaming, speculative execution, reservation stations, a reorder buffer, and in-order retirement to manage multiple instructions in flight.

Keeping the pipeline supplied

The front end combines branch prediction, a branch target buffer, return-address handling, a fetch buffer, and instruction prefetching. The memory system includes a load-store queue, non-blocking caches, and buffered store/writeback paths.

My contribution

I contributed across nearly all parts of the project, working on processor design, integration between stages, debugging, and verification. This was a team effort with David Gonzalez, Westin James, Joshua Mier, and Josh Weingarden.

Verification and documentation

The project includes directed testbenches, C and assembly workloads, simulation and synthesis scripts, benchmark records, and a final team report. Testing focused on architectural correctness, pipeline interactions, and recovery behavior in the course toolchain.

Completed projectSource, tests, build scripts, and the team report are supplied. Portfolio review did not rerun HDL simulation or synthesis; FPGA hardware operation is not claimed.
