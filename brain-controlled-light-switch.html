Embedded systems / Brain–computer interfaces

From brain waves to a light switch.

Mind Switch connects a NeuroSky MindWave headset to light control through Python. The uploaded prototype includes direct smart-plug control and a separate ESP32 serial-control path.

MY ROLE

Technical Lead & Lead BCI Developer

The idea

Turn EEG-derived attention readings into a simple physical response, exploring how a headset, packet parser, and output device work together.

What the source shows

Python reads headset packets and checks their checksums. One script switches a Kasa smart plug when attention crosses 60 and remembers the last requested state. A second script sends ON/OFF commands to an ESP32 over serial.

Two ways to control an output

The smart-plug and ESP32 scripts are alternate implementations. A third script tests the plug by switching it off and on. The project includes three Python scripts for control and hardware testing.
