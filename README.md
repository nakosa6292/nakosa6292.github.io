# Noah Stein — Personal Website

Static portfolio prepared for nakosa6292.github.io. Upload all files in this folder to the repository root, including index.html and .nojekyll. No Python scripts or build step are required.

## Publish

Create a public repository named nakosa6292.github.io under nakosa6292. Upload these extracted files (not the ZIP or enclosing folder) and commit. In Settings > Pages choose Deploy from a branch, main, and / (root); Save. Check the Pages screen for the deployed address.

## Edit text

Open the relevant HTML file on GitHub and select the pencil/Edit button. Change the wording between tags such as <h1>, <h2>, and <p>, keeping the tags, quotes, and links intact. Commit changes directly to main. GitHub Pages redeploys automatically.
