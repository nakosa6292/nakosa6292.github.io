Machine learning / Neurotechnology

Learning to recognize motor intent.

A collection of motor-imagery EEG experiments spanning LDA, CSP/SVM, an EEGNet-style convolutional network, and visualizations of predicted movement.

PYTHON / SYSTEM STUDYCONCEPTUAL ILLUSTRATION

MY ROLE

Lead Machine Learning Engineer & BCI Research Developer

From recordings to features

I tested this completed project successfully using EEG recordings from an online motor-imagery dataset. The training scripts load four-class subject 1 data through MOABB and explore filtering, log-variance features, common spatial patterns, and feature selection.

The learning approaches

The source includes LDA, RBF and linear SVM experiments, plus an EEGNet-style network implemented in TensorFlow/Keras. The CNN uses temporal, depthwise spatial, and separable convolutions and saves a model with held-out input data.

From predictions to movement

Matplotlib visualizations replay model predictions as point locations, arm poses, and stick-figure actions. The two-link arm smooths changes in joint angles. Separate headset utilities explore live serial data and signal visualization.

What worked — and the hardware limit

The classification and simulation worked with the recorded online EEG data. My lower-cost NeuroSky MindWave headset was not compatible with this pipeline. The completed demonstration therefore uses recorded dataset trials; live motor-imagery control from that headset was not part of the working setup.
